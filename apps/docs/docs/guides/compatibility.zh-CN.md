# 兼容范围与限制

## 图片与 PDF

工作区新增独立图片和 PDF 插件。图片使用浏览器解码器，AVIF 支持取决于浏览器。PDF 使用固定版本 PDF.js 和同版的本地 Worker、CMap、字体及 WASM 资源，部署方式见 [图片与 PDF](./image-pdf)。新增浏览器与消费用例已编写，尚待统一运行和性能测量。Canvas 与文本缓存预算不代表整个浏览器进程的内存上限。

## 纯文本、JSON 和 Markdown

新增格式通过独立插件接入，详见 [纯文本、JSON 与 Markdown](./text-formats)。文本支持结合 BOM、来源 charset 和字节特征自动识别 UTF-8、UTF-16、GBK/GB18030，并可手动切换。JSON 按原文范围保留数字和重复键；Markdown 支持基础排版、表格、任务列表和按需代码高亮，不包含公式、Mermaid 或编辑器。原文窗口化不等于文件大小无限，仍需配置资源限制。

兼容结论以实际消费与浏览器验证为依据，不代表所有办公软件、构建器或文件都能逐像素还原。当前版本为工作区预览版。

## 已验证组合

| 宿主/工具 | 已验证版本或方式                                | 说明                                         |
| --------- | ----------------------------------------------- | -------------------------------------------- |
| React     | 18.3.1、19.2.0                                  | @fivo/react；包含 React 18 开发态 StrictMode |
| Vue 3     | 3.5.43                                          | @fivo/vue；包含 KeepAlive 激活恢复           |
| Vue 2     | 2.6.14、2.7.16                                  | @fivo/vue2；Options API 与 KeepAlive         |
| 原生 JS   | Vite 5.4.21 与仓库 esbuild 示例                 | 不安装 React                                 |
| 包消费    | pnpm 11.10.0、npm、Yarn 1.22.22 独立宿主        | 包产物通过实际 tarball 安装                  |
| 资源部署  | 默认 Worker、非根 base、自动样式与严格 CSP 测试 | 特殊部署仍需宿主验证                         |

工作区统一使用 pnpm；宿主可以使用自己的包管理器。不要把宿主使用 npm/Yarn 与仓库混用多个锁文件混为一谈。

Office 公开声明不依赖 React/Vue 或内部解析器声明。仓库的文档站使用 React/Ant Design，不代表原生和 Vue 宿主必须安装它们。

## 文件格式

| 解析族     | 扩展名                           |
| ---------- | -------------------------------- |
| DOC / DOCX | .doc、.wps / .docx、.docm、.dotx |
| XLS / XLSX | .xls / .xlsx、.xlsm、.xltx       |
| PPT / PPTX | .ppt / .pptx、.pptm、.potx       |

文件名/MIME 只参与识别，不能把 PDF 改名为 DOCX 后预览。OOXML 压缩包和二进制容器还要通过实际内容解析。宏启用扩展名用于只读内容预览，不执行宏代码。

## 排版与功能边界

- Word：字体、分页、浮动对象、复杂表格和修订可能与 Office/WPS 有差异。
- Excel：支持既有缓存值和静态业务语义展示，不提供完整公式重算、数据编辑或外部数据连接。
- PPT：复杂母版、SmartArt、艺术字、动画与媒体编码不保证全部还原；转场是已支持子集。
- 图片：浏览器解码、矢量转换和资源内容决定是否可呈现；损坏或不支持的格式通过错误/告警反馈。
- 批注、修订、水印、阅读模式是只读预览能力，不意味着具备编辑保存。

## 浏览器与框架

目标是支持现代 DOM、Worker、ResizeObserver、Blob 和 ESM 的浏览器，不支持 IE11。Vue 2 支持不隐含 Webpack 4、旧 Chromium 或全部 SSR 框架的默认配置可用。

纯模块导入可用于服务端构建场景，但创建查看器、读取 File 和挂载渲染应在客户端执行。Next.js 等宿主需要明确客户端边界；未验证的构建器应检查 Worker 和资源输出。

## 大文件与性能

长文档采用渐进解析和窗口化呈现。首屏就绪、全部分页完成、图片加载完成是不同状态。内存、压缩包展开量、字体数量、表格尺寸和媒体大小都影响性能。

按真实文件分布配置资源限制并定向压测；不要宣称固定毫秒内加载或不限制文件大小。停用视图可减少呈现工作，但不等同于释放会话；离开页面调用 destroy。

## 安全与资源部署

- 文件本地解析不等于可以信任任意文件。对来源、大小、超时和压缩比设置符合业务的边界。
- 外部字体、媒体和链接受浏览器 CORS、CSP 与组件资源策略约束。
- 自动样式使用 style 标签与版本作用域；严格 CSP 需正确 nonce，动态样式属性仍受 style-src-attr 限制。
- 自定义 workerFactory 必须指向可访问的模块 Worker；返回 HTML/404 的路径不能工作。
- 不将真实文件、授权头、用户隐私内容纳入公开站点或 CI 截图。

## 验证建议

对目标框架、生产打包器、部署子目录及代表性文档做真实浏览器检查。至少覆盖文件打开、连续切换、缩放、查找、图片弹层、销毁和自动样式。类型检查通过只能证明声明一致，不能替代视觉验收。

CSV/TSV、XML、Code 可使用独立 @fivo/csv、@fivo/xml、@fivo/code 插件；JSONC/JSONL/NDJSON 由 @fivo/json 处理，标准预设均已注册。默认参数、预算、懒加载与外部样式说明见[文本格式指南](./text-formats)。
